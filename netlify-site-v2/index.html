GitGuardian — Customer Health & Engagement Dataset

This dataset contains customer, product usage, and support data for a B2B SaaS platform. Three CSV files are available:

Available Files

File Description Rows
raw_customers.csv Customer accounts and subscription info ~30
raw_daily_usage.csv Daily product feature usage per customer ~7,000
raw_support_tickets.csv Support tickets with priority and resolution ~200

Schema

raw_customers

ColumnTypeDescription
customer_idstringCustomer identifier
company_namestringCompany name
planstringSubscription plan
mrrintegerMonthly recurring revenue ($)
signed_up_atdateSignup date
regionstringDeployment region
acquisition_sourcestringHow the customer was acquired
num_seatsintegerLicensed seats
churned_atdateChurn date (empty if active)

raw_daily_usage

ColumnTypeDescription
usage_idstringUsage record identifier
customer_idstringCustomer identifier
datedateActivity date
feature_namestringProduct feature used
event_countintegerNumber of times the feature was used
session_minutesfloatTime spent in session (minutes)

raw_support_tickets

ColumnTypeDescription
ticket_idstringTicket identifier
customer_idstringCustomer identifier
categorystringTicket category
prioritystringcritical / high / medium / low
statusstringopen / in_progress / resolved / closed
created_attimestampWhen the ticket was created
resolved_attimestampWhen the ticket was resolved (if applicable)

Note: This is raw data — it may contain quality issues typical of production systems.
