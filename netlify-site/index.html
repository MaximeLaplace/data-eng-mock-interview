GitGuardian — Secret Detection Analytics Dataset

This dataset represents raw data from a secret detection platform. Three CSV files are available for download:

Available Files

File Description Rows
raw_organizations.csv Customer organizations ~25
raw_scan_events.csv Repository scan events ~400
raw_incidents.csv Detected secret incidents ~600

Schema

raw_organizations

ColumnTypeDescription
org_idstringOrganization identifier
org_namestringOrganization name
plan_typestringSubscription plan
signed_up_attimestampSignup date
industrystringIndustry vertical
employee_countintegerCompany size

raw_scan_events

ColumnTypeDescription
event_idstringUnique scan event ID
repo_idstringRepository scanned
org_idstringOrganization that owns the repo
scanned_attimestampScan timestamp (UTC)
scan_typestring'initial' or 'incremental'
files_scannedintegerNumber of files scanned
duration_msintegerScan duration in milliseconds

raw_incidents

ColumnTypeDescription
incident_idstringUnique incident ID
event_idstringScan event that found this incident
detector_namestringType of secret detected
severitystringcritical / high / medium / low
statusstringopen / resolved / ignored
detected_attimestampDetection timestamp
resolved_attimestampResolution timestamp (if resolved)
Note: This is raw data — it may contain quality issues typical of production systems.
